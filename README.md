# Рефразирование диалоговых запросов для поиска медиаконтента

Исследовательский проект по **conversational query rewriting**: восстановление самостоятельного поискового запроса из текущей реплики пользователя и предшествующего диалога. Предметная область — **фильмы и мультфильмы**.

Работа подготовлена в рамках отбора в мастерскую **VK «Рефразеры для поиска медиаконтента»** (2026).

[**Открыть исследование в Google Colab**](https://colab.research.google.com/github/Relock203/media-content-query-rewriting/blob/main/Media_Content_Query_Rewriting.ipynb) · [**Посмотреть ноутбук на GitHub**](Media_Content_Query_Rewriting.ipynb)

## Задача и подход

Реплика «А из девяностых?» не содержит полноценного поискового намерения без контекста. Рефразер преобразует её вместе с историей диалога в самостоятельный запрос, например «Фильмы про путешествия во времени из девяностых годов».

Эксперимент состоит из двух частей:

1. **Рефразирование:** GigaChat-2, базовый и улучшенный системные промпты; сравнение смысловой корректности ответов.
2. **Поиск:** эмбеддинги `intfloat/multilingual-e5-small`, нормализованные векторы и косинусное сходство; сравнение выдач по исходному, рефразированному и эталонному запросам.

Используется набор из **45 диалоговых сценариев** (35 для разработки и 10 для отложенного тестирования). Поисковый корпус — **38 923 записи** с русскоязычными описаниями фильмов и мультфильмов из [Movie Plots from Wikipedia in Russian](https://www.kaggle.com/datasets/maksimpotorochin/movie-plots-from-wikipedia-in-russian).

## Результаты

### Смысловая корректность рефразирования

| Выборка | Базовый промпт V1 | Улучшенный промпт V2 |
|---|---:|---:|
| Dev, 35 сценариев | 25/35 (71,4%) | 29/35 (82,9%) |
| Test, 10 сценариев | Не оценивался | 5/10 (50,0%) |

На отложенном тесте V2 корректно обработал **2 из 7** сценариев, требующих восстановления контекста (**28,6%**), и **3 из 3** самостоятельных запросов. Тестовые диалоги в среднем длиннее разработочных; эти выборки не позволяют отдельно оценить влияние сложности и подбора промпта.

### Качество поиска

По десяти тестовым сценариям разметка охватывает **101 пару «сценарий — запись корпуса»**. Документы отмечались как релевантные (`1`), нерелевантные (`0`) или неопределённые (`?`). Нижняя оценка P@5 считает `?` нерелевантными, верхняя — релевантными; **это не доверительные интервалы**.

| Запрос | Нижняя P@5 | Верхняя P@5 |
|---|---:|---:|
| Original — последняя реплика | 0,04 | 0,06 |
| Rewritten — результат рефразера | **0,20** | **0,40** |
| Reference — смысловой эталон | 0,12 | 0,26 |

Нижняя P@5 улучшилась в пяти тестовых сценариях и не изменилась в пяти. На этой небольшой выборке при принятой разметке рефразирование помогло поиску, но результаты **не доказывают эффективность на произвольных пользовательских диалогах**.

## Как изучить и воспроизвести

**Для просмотра исследования:** откройте ноутбук по ссылке выше. Сохранённые в нём результаты, графики и таблицы можно изучать без ключа GigaChat и без пересчёта эмбеддингов.

**Для повторного запуска:**

1. Откройте ноутбук в Google Colab. Для GPU-кодирования корпуса предпочтительна среда с видеокартой.
2. Выполните подготовку датасета и раздел рефразирования. При отсутствии секрета `GIGACHAT_CREDENTIALS` подключение к API и живая демонстрация пропускаются; результаты промптов читаются из JSON на GitHub.
3. Полный последовательный запуск **раздела 4** скачивает исходный датасет Kaggle, проверяет SHA-256 и **заново строит индекс из 38 923 документов** с помощью PyTorch и Sentence Transformers. Это вычислительно затратный шаг. Для простого ознакомления он **не нужен**: выдачи и итоговые оценки сохранены в файлах выше.
4. Для новой генерации запросов понадобится собственный доступ к GigaChat API; креденшелы нельзя добавлять в ноутбук или репозиторий.

**Важно:** среда, версии сторонних пакетов и удалённые ресурсы могут изменяться. Опубликованные поисковые результаты относятся к зафиксированному в JSON хешу корпуса. Полный чистый запуск на новой среде отдельно не гарантируется.

## Ограничения

- Тестовая выборка — 10 сценариев, часть примеров синтетическая.
- Разметка релевантности проводилась с участием ChatGPT и не является независимой оценкой несколькими экспертами.
- В корпусе встречаются дубликаты произведений с разными значениями поля `type`; единицей ранжирования является **строка корпуса**, а не уникальное произведение.
- Семантический поиск по косинусному сходству не проверяет логически все запреты, исключения и отсутствующие метаданные.
- Более высокая P@5 у Rewritten по сравнению с Reference не означает более высокую смысловую точность рефразера.
